# Security policy

## Supported versions

Only the latest release on `main` receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub private vulnerability reporting](../../security/advisories/new) or by
email to phoenixpinnock@gmail.com.

Include a description, steps to reproduce and the potential impact. You can
expect an acknowledgement within a few days.

## Scope

This is a static personal portfolio with no backend, authentication or user
data. Secrets, client data and private repository details must never be
committed; if you find any, report it using the channel above.
